SaltyKeys.js requires modern browser features and will not work in older browsers or Internet Explorer.

## Minimum Browser Versions

| Browser | Minimum Version | Released |
|---------|----------------|----------|
| **Chrome** | 92 | July 2021 |
| **Firefox** | 90 | July 2021 |
| **Safari** | 15 | September 2021 |
| **Edge** | 92 | July 2021 |
| **Internet Explorer** | ❌ Not supported | - |

<Aside type="note">
These version requirements are based on ES2022 private class fields support, which is the most recent feature used by SaltyKeys.
</Aside>

## Required Browser Features

### ES6+ Features (2015-2017)

✅ **Classes**
```js
class SaltyKeys { /* ... */ }
```

✅ **Arrow Functions**
```js
const func = () => { /* ... */ };
```

✅ **Template Literals**
```js
const str = `Hello ${name}`;
```

✅ **Const/Let**
```js
const value = 'immutable';
let variable = 'mutable';
```

✅ **Default Parameters**
```js
function example(param = 'default') { /* ... */ }
```

### ES2022 Features

✅ **Private Class Fields**
```js
class SaltyKeys {
  #privateField = 'value';
}
```

This is the **most restrictive requirement**. Private class fields (`#field`) are only available in:
- Chrome/Edge 74+ (full support in 92+)
- Firefox 90+
- Safari 14.5+ (full support in 15+)

### Web APIs

✅ **Base64 Encoding/Decoding**
```js
btoa('string');  // Encode
atob('encoded'); // Decode
```
Supported in all modern browsers.

✅ **Regular Expressions**
```js
/pattern/.test(string);
string.match(/pattern/);
```
Universal support.

✅ **URL APIs**
```js
window.location.href;
new URLSearchParams(window.location.search);
```
Supported in all modern browsers.

✅ **DOM Query Selectors**
```js
document.querySelector('meta[name="..."]');
```
Supported in all modern browsers.

## Feature Detection

You can detect if a browser supports SaltyKeys:

```js
function isSaltyKeysSupported() {
  try {
    // Test for private class fields
    eval('class Test { #private }');

    // Test for required APIs
    if (typeof btoa === 'undefined' || typeof atob === 'undefined') {
      return false;
    }

    return true;
  } catch (error) {
    return false;
  }
}

if (isSaltyKeysSupported()) {
  console.log('✓ SaltyKeys is supported');
} else {
  console.log('✗ Browser too old for SaltyKeys');
}
```

### Graceful Degradation

Provide a fallback for unsupported browsers:

```html
<script>
function isBrowserSupported() {
  try {
    eval('class T { #p }');
    return typeof btoa !== 'undefined';
  } catch {
    return false;
  }
}

if (!isBrowserSupported()) {
  document.body.innerHTML = `
    <div style="padding: 20px; background: #fee; border: 2px solid #c00;">
      <h2>Browser Not Supported</h2>
      <p>This application requires a modern browser.</p>
      <p>Please update to:</p>
      <ul>
        <li>Chrome 92+ or Edge 92+</li>
        <li>Firefox 90+</li>
        <li>Safari 15+</li>
      </ul>
    </div>
  `;
}
</script>
```

## Known Browser-Specific Issues

### Safari < 15

Private class fields are partially supported in Safari 14.5-14.9 but have bugs. **Safari 15+** is required for stable operation.

### Firefox < 90

Private class fields not supported. Firefox 90 (July 2021) added full support.

### Chrome < 74

Private class fields not supported. Chrome 74 (April 2019) added basic support; Chrome 92 is recommended.

### Internet Explorer

❌ **No support whatsoever.** IE lacks:
- Private class fields
- Many ES6+ features
- Modern JavaScript syntax

<Aside type="caution">
Internet Explorer is end-of-life and no longer receives security updates. Microsoft officially ended support in June 2022.
</Aside>

## Polyfills and Transpilation

### Can SaltyKeys be polyfilled?

**Partially, but not recommended.**

- ✅ ES6 features can be transpiled with Babel
- ❌ Private class fields require complex transforms
- ❌ The transformed code would be significantly larger
- ❌ Performance would be worse

### Should you transpile SaltyKeys?

**No.** If you need to support older browsers:

1. **Use a different approach** (server-side keys)
2. **Require modern browsers** for your demo/tutorial
3. **Provide a fallback message** for old browsers

The educational use case for SaltyKeys typically targets developers who already have modern browsers.

## Progressive Enhancement Strategy

For production applications (using a server-side proxy), you can progressively enhance:

```js
// Check if SaltyKeys is available (modern browser)
if (typeof SaltyKeys !== 'undefined' && isBrowserSupported()) {
  // Enhanced experience with local features
  initializeWithSaltyKeys();
} else {
  // Fallback experience
  initializeWithFallback();
}
```

## Checking Your Browser

Want to check if your current browser supports SaltyKeys?

```js
// Run this in your browser console:
(function() {
  const checks = {
    'Private fields': false,
    'btoa/atob': typeof btoa !== 'undefined' && typeof atob !== 'undefined',
    'Classes': false,
    'Arrow functions': false
  };

  try { eval('class T { #p }'); checks['Private fields'] = true; } catch (e) {}
  try { eval('class C {}'); checks['Classes'] = true; } catch (e) {}
  try { eval('() => {}'); checks['Arrow functions'] = true; } catch (e) {}

  console.table(checks);

  const supported = Object.values(checks).every(v => v);
  console.log(supported ? '✓ Your browser supports SaltyKeys!' : '✗ Browser not supported');
})();
```
