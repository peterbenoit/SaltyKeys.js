## `SaltyKeys.getPenId()`

Extracts and returns the unique identifier from the current context (e.g., CodePen Pen ID).

### Syntax

```js
const id = SaltyKeys.getPenId();
```

### Parameters

None.

### Returns

| Type | Description |
|------|-------------|
| `string \| null` | The extracted ID, or `null` if extraction fails |

### Examples

```js
// In CodePen: https://codepen.io/user/pen/abc123
const id = SaltyKeys.getPenId();
console.log(id);  // "abc123"

// On a non-CodePen page (without configuration)
const id = SaltyKeys.getPenId();
console.log(id);  // null
```

### Behavior

1. **First call**: Extracts ID from URL using the configured pattern or canonical link
2. **Subsequent calls**: Returns cached value (if caching is enabled)
3. **Returns `null`** if:
   - No match found in the URL
   - No canonical link exists
   - Custom `getPenId()` returns `null`

### Performance

- **First call**: ~0.1ms (URL regex matching)
- **Cached calls**: ~0.01ms (returns cached value)

## `SaltyKeys.generateSaltedKey(apiKey)`

Generates a salted (obfuscated) version of an API key tied to the current context.

### Syntax

```js
const saltedKey = SaltyKeys.generateSaltedKey(apiKey);
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `apiKey` | `string` | Yes | Your original API key to obfuscate |

### Returns

| Type | Description |
|------|-------------|
| `string` | The salted key, ready to embed in your code |

### Throws

Logs a warning (doesn't throw) if:
- `apiKey` is empty or not a string
- Context ID cannot be extracted (returns `null`)

### Examples

**Basic usage:**
```js
const salted = SaltyKeys.generateSaltedKey('my-api-key-123');
console.log(salted);
// "MTcyMDM4MDAwMDEyMw==_nonce123_YWJj...==_U2t..."
```

**Multiple keys:**
```js
const weatherKey = SaltyKeys.generateSaltedKey('weather-api-key');
const mapsKey = SaltyKeys.generateSaltedKey('maps-api-key');

// Use them in your code
const WEATHER_KEY_SALTED = weatherKey;
const MAPS_KEY_SALTED = mapsKey;
```

**With special characters:**
```js
// Unicode and special characters are handled safely
const salted = SaltyKeys.generateSaltedKey('key-with-émojis-🔑');
// Works correctly
```

### How It Works

The salted key contains:

1. **Timestamp** (Base64 encoded) — when the key was generated
2. **Nonce** (random string) — adds randomness
3. **Context ID** (Base64 encoded) — the Pen ID or custom ID
4. **API Key** (double Base64 encoded) — your actual key

Format: `timestamp_nonce_contextId_apiKey`

All parts use Unicode-safe encoding to handle special characters.

### Important Notes

<Aside type="caution" title="Generate in console, not in code!">
Always run `generateSaltedKey()` in your browser console in the context where you'll use it. Never include your real API key in visible code:

```js
// ❌ WRONG - exposes your real key
const realKey = 'my-api-key';
const salted = SaltyKeys.generateSaltedKey(realKey);

// ✅ RIGHT - run this in console, then copy the output
SaltyKeys.generateSaltedKey('my-api-key')
// Copy the result and use it in your code:
const SALTED = 'MTcyMD...';  // Paste the output here
```
</Aside>

<Aside type="note">
Each time you generate a salted key, it will be **different** (due to timestamp and nonce), but all variations decode to the same API key in the correct context.
</Aside>

## `SaltyKeys.getApiKey(saltedKey)`

Retrieves the original API key from a salted key, validating the current context.

### Syntax

```js
const apiKey = SaltyKeys.getApiKey(saltedKey);
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `saltedKey` | `string` | Yes | The salted key previously generated |

### Returns

| Type | Description |
|------|-------------|
| `string \| null` | The original API key if validation passes, or `null` if it fails |

### Examples

**Basic usage:**
```js
const saltedKey = 'MTcyMDM4MDAwMDEyMw==_...';
const apiKey = SaltyKeys.getApiKey(saltedKey);

if (apiKey) {
  console.log('✓ Key retrieved successfully');
  // Use the API key
} else {
  console.error('✗ Failed to retrieve key');
}
```

**With API requests:**
```js
const SALTED_KEY = 'MTcyMDM4MDAwMDEyMw==_...';

async function fetchData() {
  const apiKey = SaltyKeys.getApiKey(SALTED_KEY);

  if (!apiKey) {
    throw new Error('API key not available');
  }

  const response = await fetch(
    `https://api.example.com/data?key=${apiKey}`
  );

  return response.json();
}
```

**Cache the decoded key:**
```js
// Decode once
const API_KEY = SaltyKeys.getApiKey(SALTED_KEY);

// Use many times
function request1() {
  return fetch(`https://api.example.com/endpoint1?key=${API_KEY}`);
}

function request2() {
  return fetch(`https://api.example.com/endpoint2?key=${API_KEY}`);
}
```

### Validation Process

When you call `getApiKey()`:

1. **Extract current context ID** — Gets the Pen ID from the current URL
2. **Decode the salted key** — Extracts all embedded components
3. **Compare context IDs** — Checks if current ID matches embedded ID
4. **Return result**:
   - ✅ If IDs match: Returns your original API key
   - ❌ If IDs don't match: Returns `null`

### When It Returns `null`

Common scenarios:

**Wrong context:**
```js
// Generated in Pen ID: abc123
// But running in Pen ID: xyz789
const key = SaltyKeys.getApiKey(saltedKey);  // null
```

**Invalid salted key:**
```js
// Truncated or corrupted key
const key = SaltyKeys.getApiKey('MTcyMD');  // null
```

**No context ID available:**
```js
// Outside of CodePen, without configuration
const key = SaltyKeys.getApiKey(saltedKey);  // null
```

**Encoding errors (rare):**
```js
// Malformed Base64 or decoding failure
const key = SaltyKeys.getApiKey(corruptedKey);  // null
```

### Error Handling Patterns

**Basic validation:**
```js
const apiKey = SaltyKeys.getApiKey(saltedKey);

if (!apiKey) {
  console.error('Could not retrieve API key');
  return;
}

// Continue with apiKey
```

**With fallback:**
```js
function getKeyOrDefault(saltedKey, defaultValue = null) {
  return SaltyKeys.getApiKey(saltedKey) || defaultValue;
}

const apiKey = getKeyOrDefault(saltedKey, 'demo-key');
```

**With error throwing:**
```js
function getKeyOrThrow(saltedKey) {
  const apiKey = SaltyKeys.getApiKey(saltedKey);

  if (!apiKey) {
    throw new Error(
      'API key could not be retrieved. ' +
      'Ensure you are running this code in the correct context.'
    );
  }

  return apiKey;
}
```

### Performance

- **Typical decode**: ~0.3ms
- **With ID caching**: ~0.25ms
- **Failed validation**: ~0.2ms (fails early)

<Aside type="tip">
If calling `getApiKey()` multiple times with the same salted key, cache the result:

```js
// Cache the result
const API_KEY = SaltyKeys.getApiKey(SALTED_KEY);

// Use the cached value
// Instead of calling getApiKey() repeatedly
```
</Aside>

### Security Note

<Aside type="caution">
Once decoded, the API key is **plain text in memory** and accessible via DevTools. This is inherent to client-side code. SaltyKeys provides obfuscation, not encryption.
</Aside>

## Method Chaining

SaltyKeys methods cannot be chained as they return values (`string`, `null`, or `undefined`), not the SaltyKeys object itself.

```js
// ❌ This doesn't work
SaltyKeys.configure({...}).generateSaltedKey('key');

// ✅ Do this instead
SaltyKeys.configure({...});
const key = SaltyKeys.generateSaltedKey('key');
```
