## `SaltyKeys.configure(options)`

Configures SaltyKeys.js with custom settings for your environment.

### Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `options` | `Object` | Yes | - | Configuration options object |
| `options.urlPattern` | `RegExp` | No | CodePen pattern | Regex to extract ID from URL |
| `options.cacheEnabled` | `Boolean` | No | `true` | Enable ID caching |
| `options.environment` | `String` | No | `'codepen'` | Environment identifier |

### Returns

`void` — This method doesn't return a value.

### Example

```js
SaltyKeys.configure({
  urlPattern: /mysite\.com\/demos\/([^?#]+)/,
  cacheEnabled: true,
  environment: 'custom'
});
```

### Default Configuration

```js
{
  urlPattern: /codepen\.io\/.*\/pen\/([^?#]+)/,
  cacheEnabled: true,
  environment: 'codepen'
}
```

## Configuration Options

### `urlPattern`

A regular expression used to extract a unique identifier from the current URL.

**Requirements:**
- Must be a valid RegExp object
- Must include a capture group `()` for the ID
- The capture group should match the unique identifier

**Examples:**

```js
// CodePen (default)
urlPattern: /codepen\.io\/.*\/pen\/([^?#]+)/
// Matches: https://codepen.io/username/pen/abc123
// Extracts: "abc123"

// JSFiddle
urlPattern: /jsfiddle\.net\/[^/]+\/([^/]+)/
// Matches: https://jsfiddle.net/username/xyz789/
// Extracts: "xyz789"

// Custom path-based
urlPattern: /\/demos\/([a-z0-9-]+)/
// Matches: https://example.com/demos/my-demo-123
// Extracts: "my-demo-123"

// Query parameter
// For query params, override getPenId() instead
```

<Aside type="caution">
The regex must have **exactly one capture group**. Multiple capture groups or no capture group will cause ID extraction to fail.
</Aside>

### `cacheEnabled`

Controls whether the extracted ID is cached for performance.

**Type**: `Boolean`
**Default**: `true`

**When enabled** (default):
```js
SaltyKeys.configure({ cacheEnabled: true });

const id1 = SaltyKeys.getPenId();  // Extracts from URL
const id2 = SaltyKeys.getPenId();  // Returns cached value
const id3 = SaltyKeys.getPenId();  // Returns cached value
```

**When disabled**:
```js
SaltyKeys.configure({ cacheEnabled: false });

const id1 = SaltyKeys.getPenId();  // Extracts from URL
const id2 = SaltyKeys.getPenId();  // Extracts from URL again
const id3 = SaltyKeys.getPenId();  // Extracts from URL again
```

**When to disable:**
- The URL might change during the page lifecycle (rare)
- You're testing different configurations dynamically
- You want to ensure the latest ID is always used

**Performance impact:**
- Enabled: ~0.01ms per subsequent call
- Disabled: ~0.1ms per call

### `environment`

A string identifier for your environment, used for logging and debugging.

**Type**: `String`
**Default**: `'codepen'`

**Example values:**
```js
environment: 'codepen'    // Default
environment: 'jsfiddle'   // JSFiddle
environment: 'jsbin'      // JS Bin
environment: 'production' // Your production site
environment: 'staging'    // Your staging environment
environment: 'local-dev'  // Local development
```

This value doesn't affect functionality, but appears in console warnings and error messages to help with debugging.

## Advanced Configuration

### Overriding `getPenId()`

For complete control over ID extraction, override the `getPenId()` method:

```js
SaltyKeys.getPenId = function() {
  // Your custom logic
  return 'your-id';
};
```

**Examples:**

**From meta tag:**
```js
SaltyKeys.getPenId = function() {
  const meta = document.querySelector('meta[name="demo-id"]');
  return meta ? meta.getAttribute('content') : null;
};
```

**From query parameter:**
```js
SaltyKeys.getPenId = function() {
  const params = new URLSearchParams(window.location.search);
  return params.get('projectId');
};
```

**From data attribute:**
```js
SaltyKeys.getPenId = function() {
  const root = document.getElementById('app');
  return root ? root.dataset.projectId : null;
};
```

**From session storage:**
```js
SaltyKeys.getPenId = function() {
  return sessionStorage.getItem('currentProjectId');
};
```

<Aside type="caution">
When overriding `getPenId()`, ensure it returns:
- A **consistent string** for the same context
- A **unique string** for different contexts
- `null` if no ID can be determined

Inconsistent IDs will cause key validation to fail.
</Aside>

## Configuration Examples

### Example 1: JSFiddle Setup

```js
SaltyKeys.configure({
  urlPattern: /jsfiddle\.net\/[^/]+\/([^/]+)/,
  environment: 'jsfiddle'
});

// Test
console.log(SaltyKeys.getPenId());
// On https://jsfiddle.net/user/abc123/ → "abc123"
```

### Example 2: Custom Demo Platform

```js
SaltyKeys.configure({
  urlPattern: /demos\.mysite\.com\/([a-z0-9-]+)/,
  cacheEnabled: true,
  environment: 'production-demos'
});

// Test
console.log(SaltyKeys.getPenId());
// On https://demos.mysite.com/weather-app → "weather-app"
```

### Example 3: Meta Tag Approach

```html
<!-- In HTML -->
<meta name="project-id" content="unique-id-123">
```

```js
// In JavaScript
SaltyKeys.getPenId = function() {
  const meta = document.querySelector('meta[name="project-id"]');
  if (!meta) {
    console.error('Project ID meta tag not found');
    return null;
  }
  return meta.getAttribute('content');
};

SaltyKeys.configure({
  environment: 'meta-tag-mode'
});
```

### Example 4: Development vs Production

```js
const isProduction = window.location.hostname !== 'localhost';

SaltyKeys.configure({
  urlPattern: isProduction
    ? /mysite\.com\/demos\/([^?#]+)/
    : /localhost:\d+\/demos\/([^?#]+)/,
  environment: isProduction ? 'production' : 'development',
  cacheEnabled: isProduction  // Disable cache in dev for testing
});
```

## Validation

After configuring, validate that ID extraction works:

```js
// Configure
SaltyKeys.configure({ /* options */ });

// Validate
const extractedId = SaltyKeys.getPenId();

if (extractedId) {
  console.log('✓ Configuration successful, ID:', extractedId);
} else {
  console.error('✗ Configuration failed - could not extract ID');
  console.log('Current URL:', window.location.href);
}
```

## Reconfiguration

You can reconfigure SaltyKeys at any time:

```js
// Initial configuration
SaltyKeys.configure({ environment: 'dev' });

// Later, reconfigure
SaltyKeys.configure({
  urlPattern: /new-pattern/,
  environment: 'production'
});
```

The new configuration completely replaces the previous one.

<Aside type="note">
Reconfiguring clears the ID cache, even if caching is enabled. The next call to `getPenId()` will re-extract the ID using the new pattern.
</Aside>
