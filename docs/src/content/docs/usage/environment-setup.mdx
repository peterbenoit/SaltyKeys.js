SaltyKeys.js is designed for CodePen by default, but can be configured for use in other environments. This guide covers setup requirements for various platforms.

## CodePen (Default)

SaltyKeys works out-of-the-box in CodePen with **zero configuration**.

### Requirements:
- ✅ No configuration needed
- ✅ Works in CodePen editor view
- ✅ Works in embedded pens
- ✅ Works in debug view

### URL Structure:
CodePen URLs follow this pattern:
```
https://codepen.io/username/pen/ABC123
                              ^^^^^^ — Pen ID extracted here
```

## JSFiddle

Configure SaltyKeys for JSFiddle:

```js
SaltyKeys.configure({
  urlPattern: /jsfiddle\.net\/[^/]+\/([^/]+)/,
  environment: 'jsfiddle'
});
```

### URL Structure:
```
https://jsfiddle.net/username/abc123/
                              ^^^^^^ — Fiddle ID
```

## JS Bin

Configure SaltyKeys for JS Bin:

```js
SaltyKeys.configure({
  urlPattern: /jsbin\.com\/([^/]+)/,
  environment: 'jsbin'
});
```

### URL Structure:
```
https://jsbin.com/abc123/edit
                  ^^^^^^ — Bin ID
```

## Your Custom Domain

### Path-Based IDs

If your demos use URLs like `https://example.com/demos/unique-id`:

```js
SaltyKeys.configure({
  urlPattern: /\/demos\/([a-z0-9-]+)/,
  environment: 'custom'
});
```

### Query Parameter IDs

If your demos use URLs like `https://example.com/demo?id=unique-id`:

```js
SaltyKeys.getPenId = function() {
  const params = new URLSearchParams(window.location.search);
  return params.get('id');
};
```

### Meta Tag IDs

If you want to embed the ID in HTML:

```html
<meta name="demo-id" content="unique-demo-123">
```

```js
SaltyKeys.getPenId = function() {
  const meta = document.querySelector('meta[name="demo-id"]');
  return meta ? meta.getAttribute('content') : null;
};
```

### Hash-Based IDs

If you use hash routing like `https://example.com#/demo/abc123`:

```js
SaltyKeys.configure({
  urlPattern: /#\/demo\/([^/?]+)/,
  environment: 'custom'
});
```

## GitHub Pages / Static Sites

For GitHub Pages or static sites with predictable paths:

```js
// If URLs are like: /project/demos/demo-001/
SaltyKeys.configure({
  urlPattern: /\/demos\/([^/]+)/,
  environment: 'github-pages'
});
```

## Local Development

For local development, you might use filenames or specific test IDs:

```js
// Option 1: Use filename as ID
SaltyKeys.getPenId = function() {
  const path = window.location.pathname;
  return path.split('/').pop().replace('.html', '');
};

// Option 2: Hardcode for local testing (not recommended for production)
SaltyKeys.getPenId = function() {
  return 'local-dev-id';
};
```

<Aside type="caution">
For local development, be aware that using a hardcoded ID means all local pages share the same context. This is fine for testing but don't use hardcoded IDs in production.
</Aside>

## Common Setup Issues

### Issue: `getPenId()` returns `null`

**Cause**: URL pattern doesn't match or capture group is wrong

**Solution**:
1. Log the current URL: `console.log(window.location.href)`
2. Test your regex at [regex101.com](https://regex101.com/)
3. Ensure you have a capture group `()`

### Issue: Keys work locally but not in production

**Cause**: Different URL structure between environments

**Solution**: Configure for the production URL pattern, or use a [meta tag approach](#meta-tag-ids) that works in both.

### Issue: Keys don't work after deployment

**Cause**: Context ID changed (e.g., different domain or path)

**Solution**: Regenerate salted keys in the production environment.
