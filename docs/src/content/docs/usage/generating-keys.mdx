Generating a salted key is the first step in using SaltyKeys.js. This process takes your real API key and creates an obfuscated version that's tied to your specific project context.

## Basic Usage

```js
const saltedKey = SaltyKeys.generateSaltedKey('your-actual-api-key');
console.log(saltedKey);
```

The salted key will be a long string of characters that looks like random gibberish:

```
MTcyMDM4MDAwMDEyMw==_abc123def456_T1RjMk5qYzJOREV6TmpFM05RPT0=...
```

## Best Practices

<Aside type="caution" title="Never generate salted keys in your visible code!">
Always generate salted keys using your browser console in the context where you'll use them. Never include your real API key in code that will be visible to others.
</Aside>

### Recommended Workflow

1. **Open your project context** (e.g., your CodePen pen)
2. **Open browser DevTools** (F12 or Right-click → Inspect)
3. **Run the generation command** in the Console tab:
   ```js
   SaltyKeys.generateSaltedKey('your-actual-api-key')
   ```
4. **Copy the output** (the salted key)
5. **Paste the salted key** into your code (not the original API key!)

### ❌ Don't Do This

```js
// WRONG - exposes your real API key!
const apiKey = 'sk-real-api-key-12345';
const saltedKey = SaltyKeys.generateSaltedKey(apiKey);
```

### ✅ Do This Instead

```js
// RIGHT - only the salted key is visible
const saltedKey = 'MTcyMDM4MDAwMDEyMw==_abc123def456_...';
const apiKey = SaltyKeys.getApiKey(saltedKey);
```

## How It Works

When you generate a salted key, SaltyKeys:

1. **Extracts the current context ID** (e.g., CodePen Pen ID)
2. **Generates a random nonce** for additional entropy
3. **Creates a timestamp** to add time-based variation
4. **Combines your API key** with these elements
5. **Applies multiple layers** of encoding (Base64, Unicode-safe encoding)
6. **Returns the salted key** as a string you can safely embed

The salted key contains:
- Your encoded API key
- The context ID (Pen ID)
- A timestamp
- A random nonce
- Multiple layers of obfuscation

## Regenerating Keys

If you need to regenerate a salted key:

```js
// Generate a new key
const newSaltedKey = SaltyKeys.generateSaltedKey('your-actual-api-key');
```

<Aside type="note">
Each time you generate a salted key, it will be **different** due to the timestamp and random nonce, even for the same API key. However, all variations can be decoded back to the original API key in the correct context.
</Aside>

## Multiple API Keys

If you need to obfuscate multiple API keys in the same project:

```js
// Generate each key separately
const apiKey1Salted = SaltyKeys.generateSaltedKey('first-api-key');
const apiKey2Salted = SaltyKeys.generateSaltedKey('second-api-key');

// Use them later
const apiKey1 = SaltyKeys.getApiKey(apiKey1Salted);
const apiKey2 = SaltyKeys.getApiKey(apiKey2Salted);
```

## Storing Salted Keys

Once generated, store salted keys as string constants in your code:

```js
// Store as constants
const WEATHER_API_KEY_SALTED = 'MTcyMDM4MDAwMDEyMw==_abc...';
const MAPS_API_KEY_SALTED = 'MTcyMDM5MDAwMDEyMw==_def...';

// Retrieve when needed
const weatherKey = SaltyKeys.getApiKey(WEATHER_API_KEY_SALTED);
const mapsKey = SaltyKeys.getApiKey(MAPS_API_KEY_SALTED);
```

## Troubleshooting

### Problem: "Unable to extract Pen ID"

**Solution**: Make sure you're generating the salted key while viewing the pen/project where you'll use it. SaltyKeys needs the context ID from the URL.

### Problem: Generated key doesn't work

**Solution**: Ensure you:
- Generated the key in the same pen where you're using it
- Copied the entire salted key (they can be very long)
- Used the correct method: `generateSaltedKey()` not `getApiKey()`

### Problem: Key works but seems insecure

**Reminder**: SaltyKeys provides **obfuscation, not encryption**. It's designed for educational use, not production security. For production apps, use server-side key management.
