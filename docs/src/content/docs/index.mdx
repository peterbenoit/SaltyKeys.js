<Aside type="caution" title="Educational Use Only">
  SaltyKeys.js is **not** a security solution. It's an educational tool demonstrating context-binding and obfuscation techniques. For production applications, always use server-side approaches for managing API keys.
</Aside>

## What is SaltyKeys.js?

SaltyKeys.js is a specialized JavaScript library designed to help developers working with CodePen projects that need to use non-sensitive API keys. It provides a client-side approach to **obfuscating and verifying API keys**, binding them to a specific CodePen context to help prevent casual extraction.

<CardGrid stagger>
  <Card title="Context-Aware" icon="approve-check-circle">
