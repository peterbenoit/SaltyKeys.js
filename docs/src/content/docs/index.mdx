## Quick Example

```js
// Generate a salted key (run this once in console)
const saltedKey = SaltyKeys.generateSaltedKey('your-api-key');

// Use the salted key in your code
const apiKey = SaltyKeys.getApiKey(saltedKey);
if (apiKey) {
  // Use your API key
}
```

## Important Disclaimer

**Warning**: This library is intended for **educational purposes only** and is **not secure** for production environments. Client-side obfuscation can be reversed by determined attackers. Always store sensitive API keys server-side in production applications.
