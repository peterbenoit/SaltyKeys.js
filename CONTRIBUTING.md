# Contributing to SaltyKeys.js

Thank you for your interest in contributing! Here's how to get involved.

## Reporting bugs

[Open an issue](https://github.com/peterbenoit/SaltyKeys.js/issues/new) and include:
- Browser and version
- CodePen URL (if applicable)
- Steps to reproduce
- Expected vs. actual behavior
- Console errors

## Submitting pull requests

1. Fork the repository
2. Create a feature branch: `git checkout -b fix/my-fix`
3. Make your changes and commit with a clear message
4. For docs changes: run `cd docs && npm run build` to verify zero errors
5. Open a pull request — one logical change per PR

See the full [Contributing guide](/project/contributing/) in the docs for details on the development setup.

## Code of Conduct
